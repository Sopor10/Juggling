## Transcription and validity audit

I read both editions visually at the cited pages. The 2014 scans reproduce the same sequences and diagrams for all eight. The source rows list each juggler's successive actions; `self` routes the edge back to the same juggler, and a named juggler routes it to that receiver. For each beat, the edge lands on the receiving juggler's next event, as shown by the arrows. All these ordinary passes and self throws have height 3 in the represented beat scale. Therefore the edge equation is `height = (target time + cycleOffset × cycleLength - source time) + 2`; every edge has target one beat later, and wrap edges carry offset 1. Each source event has one outgoing edge, each target has one incoming edge, and all event IDs and endpoints are unique and resolvable.

The source explains that an odd number of actions per row is repeated with the other hand. The JSON doubles the 3-beat, 5-beat, and 3-beat rows to cycles of 6, 10, and 6 respectively; this gives every juggler alternating R/L labels across the cycle boundary. Even-length rows use their stated period directly. There is no half-beat phase in these eight diagrams: the three rows have aligned columns, and each says all three jugglers start with the same hand allocation. The descriptions of two-count/four-count, three-count, one-count, and countdown specify the rhythmic organization; the diagrams and action rows determine the causal graph. `Suburban terror`'s “chocolate bar” is still a pass to Ben and does not change its causal endpoint.

The 2017 and 2014 page links in the JSON include exact PDF page anchors. The 2017 file uses PDF page = printed page + 1 in this range; the 2014 file's printed page matches its PDF page. Pattern identities follow the titles as printed. No alternate-name alias was added.

## Not included / blockers

This batch is partial rather than a claim that every graph in printed pp. 106–120 is transcribed. Six records already present in the JSON are carried forward without retranscription. The five independent slow-fast seven-club diagrams on printed pp. 109–110 remain open: `highgate-sevenclubthreecountvstwocount`, `highgate-technovstwocount`, `highgate-sevenclubpasspassselfvstwocount`, `highgate-sevenclubtwocountvsonecount`, and `highgate-sevenclubpasspassselfvsonecount`. They use different throw rhythms for Anne and Ben, so their nonuniform event times and corresponding heights need a dedicated derivation from the arrows; I have not guessed them. Existing catalog duplicates among the seven-club patterns and countdown variations were not duplicated. Conceptual pages on ins/outs and six-handed siteswap recipes do not introduce independent named patterns. Manipulations, including “Programming in Why Rei,” are excluded by request.

The remaining three-person diagrams have exact source locations but need a careful causal-graph pass before representation: Martin's mildness/madness is on printed p. 118 / PDF p. 119 and contains zip plus hold events and the alias by relabeling Ben; Martin's neurosis/psychosis is on printed p. 119 / PDF p. 120 and has hold events, half-beat phase offsets, and a relabeling alias; Scattered sunshine starts on printed p. 119 / PDF p. 120 and continues on printed p. 120 / PDF p. 121, with a “hurried” throw; pass-pass-zip feeding three-count and French three-count are on printed p. 120 / PDF p. 121; these include zip and heff throws; and Jim's two-count feed to Rachel's feed starts on printed p. 120 / PDF p. 121 but continues beyond this range. They have not been silently approximated as ordinary height-3 passes. Existing catalog duplicates and alias-derived relabelings are also not repeated in this chunk.

The six existing records are carried forward unchanged. `Highgate106To120StandaloneRecordValidationTests` constructs all 14 JSON records as `CausalDiagramEditorState`, calls `SynchronizeHeights()`, verifies that all serialized cycle offsets are preserved, and requires `IsValidForEditor()` to pass. It also checks record ID uniqueness, edge counts, and resolvable endpoints. The catalog-wide validity test and reviewed-ID allowlist cover the eight imported patterns; both focused tests pass.
