# Highgate pattern repair work in progress

This file tracks patterns that remain invalid after at least three source-based repair attempts. Their data lives in a separate WIP resource and a separate editor selection group so they remain loadable and editable. They are excluded from the production preset catalog until a source-backed correction makes them valid.

The catalog validity gate is `PresetCatalog_EveryPresetCreatesAValidPattern` in `Siteswaps.Test/CausalDiagram/CausalDiagramEditorStateTests.cs`. It checks production preset objects with `IsValidPattern`; it is intentionally not weakened to make these entries pass.
