# Highgate printed pp. 331–340: index ending

In the 2017 expanded PDF, printed pp. 331–340 (PDF pp. 332–341) are the Index and User-Defined Index. They contain names and references to patterns elsewhere in the book, but no causal diagrams or pattern instructions to transcribe. The last pattern pages are printed pp. 321–330, transcribed where graphable in [highgate-transcriptions-321-330.json](highgate-transcriptions-321-330.json) with the method note in [highgate-transcriptions-321-330.md](highgate-transcriptions-321-330.md).

Index references must not be treated as pattern source pages. For example, the thirteen-club three-count box is indexed at printed p. 315 and its diagram is in the earlier body, even though index cross-references appear on pp. 331–340. No graph records are added for the index pages.
