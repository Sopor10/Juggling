# Highgate source audit: Seven club one count

## Source-page reconciliation

The 2017 inventory/index reference is printed p. 33, but the body section headed **Seven club one count** is on printed p. 30 / physical PDF p. 31. Printed p. 33 / physical PDF p. 34 is the end of the preceding siteswap recipe and does not contain this section. The corresponding section is on 2014 PDF p. 16. The 2017 and 2014 prose agrees: Anne stands on Ben's shoulders, injects one club from each hand into Ben's five-club pattern, and takes clubs back; the text then identifies the resulting seven-club one-count pattern with the five-object siteswap `5`.

Sources: [2017 expanded Highgate PDF, PDF p. 31](https://jugglingedge.com/pdf/highgate.pdf#page=31); [2014 Highgate PDF, PDF p. 16](https://passing.zone/wp-content/uploads/highgate.pdf#page=16).

## Why this is not a complete standalone causal graph

Neither body page gives a complete causal diagram or an ordered throw row for the base seven-club one-count pattern. The paragraph explains a club-exchange metaphor, not the event-by-event graph. In particular, it does not specify:

- which event on Ben's cascade receives each of Anne's two injections, or the cycle phase at which she injects them;
- which event and hand on Anne's lane receives each club she “steals” back, and the corresponding causal arrow endpoints;
- how the two-hand injection/return process repeats as a full period, including its starting phase and any hand alternation at the cycle boundary;
- a diagram that determines straight versus crossing routes for all base-pattern passes.

The page's three causal diagrams are for **Double heff (64)**, **Triple pass self (753)**, and **Triple self (73)**. Their captions and prose specify trick sequences and pauses/holds, but those are separate variants and do not supply the missing base-pattern arrows or phase. A generic interpretation of the word “one count” or the siteswap `5` would require assumptions about those absent endpoints and phases, so no standalone source graph, runtime preset, or source-record test is added.

The source supports the pattern's name, seven-club count, one-count label, and its association with five-object siteswap `5`; it does not uniquely determine a complete causal diagram for the base pattern.
