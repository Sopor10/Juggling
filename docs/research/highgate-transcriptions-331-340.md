# Highgate index entries 331–334: thirteen-club weaves

The 2017 PDF pages 331–340 are the user-defined index. The four entries in
this range point to pattern diagrams on printed pages 327–330 (PDF pages
328–331). All four diagrams also appear in the 2014 PDF on pages 235–238.
The index pointers are not the body-page citations.

The two transcribed records are stored separately from the editor catalog in
[`highgate-transcriptions-331-340.json`](highgate-transcriptions-331-340.json).
Their focused test compares each graph to its named base graph, validates all
throw endpoints, synchronizes heights without retiming edges, and confirms the
resulting editor state is valid. Club multiplicity, club colors, and walking
geometry remain notation because the current causal-edge model does not encode
them.
