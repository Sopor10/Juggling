pattern diagrams. Four index entries carry locator numbers 331–334. I checked
each locator against the actual pattern heading and printed footer: these

The two fully transcribed graphs are stored separately from the editor catalog
in [`highgate-transcriptions-331-340.json`](highgate-transcriptions-331-340.json).
The focused validity test enumerates every record in that chunk, checks both
edition links and page anchors, compares each graph to its named base graph,
validates complete and resolvable edge endpoints, synchronizes heights without
retiming edges, and confirms each editor state is valid. No additional
independent graph was added: the remaining distinct diagram, *It's a good one*,
has cross-lane endpoints that remain unverified. Club multiplicity, club
colors, and walking geometry remain notation because the current causal-edge
model does not encode them.
