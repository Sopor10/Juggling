# Highgate Collection: pattern inventory audit

## Scope and method

This is an independent cross-check list, not a translated dataset. It was generated from the bundled `Siteswaps.Mcp.Server/Resources/highgate.pdf` (246 PDF pages, Aidan Burns). I extracted its contents pages and the complete alphabetical index with `pdftotext -layout`. The page references below are the book’s printed page numbers; in this PDF they match the corresponding PDF page numbers. The index pages themselves are PDF pages 239–246.

The index contains pattern names, variants, aliases, sections, and cross references; entries are therefore candidates rather than a claim that every term is a standalone diagram. The table keeps the index wording and all listed page references so the main inventory can compare against the source.

**Manipulation flag rule:** mark `YES` only where the source explicitly labels the transition as hijacking/lo-jacking. In Highgate, these are individual jugglers intentionally switching patterns by sending a “hijack club” into a hand expecting a zip; this is a pattern-transition manipulation, not the separate three-person role of an external manipulator. Every other entry is `UNCLEAR` based on title/index evidence alone. Movement terms such as *runaround*, *walking*, *weave*, and *feed* are not marked manipulation without stronger evidence.
